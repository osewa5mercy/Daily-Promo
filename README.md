# Daily Promo Bot 🎯

A Telegram bot that provides daily promo codes, deals, and discounts across various categories.

## Features
- 🎯 Daily promo codes
- 📂 Category deals (Fashion, Food, Tech, Travel)
- ⭐ Point system
- 🔥 Streak tracking
- 🏆 Leaderboard competition
- 📊 Personal statistics

## Commands
- `/start` - Main menu
- `/promo` - Get daily promo
- `/categories` - Browse deal categories
- `/stats` - View your stats
- `/leaderboard` - View top users
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
